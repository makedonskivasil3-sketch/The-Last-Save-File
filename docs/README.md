# Which documents decide what

There are about sixty documents in `docs/`. Most are the history of earlier passes. **Only the ones below govern.** Where any other document disagrees with them, it is history and they win.

| Question | Authoritative document |
|---|---|
| What is true in the story; what characters believe; what the player has seen | [`production/TRUTH_TABLE.md`](production/TRUTH_TABLE.md) |
| Decisions only the author can make, and the ones they made | [`CANON_DECISIONS.md`](CANON_DECISIONS.md) |
| The reasoning behind the colours and the Owner's goal (decided 2026-10-29) | [`production/CANON_PROPOSAL_2026-10-28.md`](production/CANON_PROPOSAL_2026-10-28.md) |
| The supporting cast: what each one does, wants and shows | [`production/CHARACTERS.md`](production/CHARACTERS.md) |
| Where the project stands, with evidence per revision | [`RELEASE_READINESS.md`](RELEASE_READINESS.md), top section only |
| Known defects and their status | [`production/ISSUE_REGISTER.md`](production/ISSUE_REGISTER.md) |
| The game to be released | [`production/PRODUCT_SPEC.md`](production/PRODUCT_SPEC.md) |
| Movement, camera, animation contact, tuning variants | [`production/MOVEMENT_SPEC.md`](production/MOVEMENT_SPEC.md); measurements in [`review/movement/`](review/movement/) |
| The opening, beat by beat | [`production/OPENING_BEATS.md`](production/OPENING_BEATS.md) |
| Wren, the relationship the slice proves | [`production/WREN_ARC.md`](production/WREN_ARC.md) |
| Stopping and resuming | [`SAVE_AND_EXIT_PROPOSAL.md`](SAVE_AND_EXIT_PROPOSAL.md) (decided and built) |
| Captions and who speaks | [`CAPTION_VOICE_CONTRACT.md`](CAPTION_VOICE_CONTRACT.md) |
| Order of events; who knows what | [`STORY_CHRONOLOGY.md`](STORY_CHRONOLOGY.md) |
| Visual style | [`ART_BIBLE.md`](ART_BIBLE.md) |
| Playtests and the observer kit | [`PLAYTEST_PLAN.md`](PLAYTEST_PLAN.md), [`playtest/`](playtest/) |
| Commercial direction (a proposal) | [`COMMERCIAL_DIRECTION.md`](COMMERCIAL_DIRECTION.md) |

**History, kept for the record:** all other files, including:
- the pass notes (`REVIEW_*`, `*_MILESTONE`, `*_PASS`, `IMPLEMENTATION_*`);
- the prompts (`prompts/`, `*_PROMPT.md`);
- `STORY_SCRIPT.md`, `NARRATIVE_BIBLE.md`, `DARK_TRUTH_DESIGN.md` and `VERTICAL_SLICE.md`.

Four of those carried a banner stating a **rejected** premise (that Rue is part of the girl). The banners were corrected on 2026-10-28.

**For a writer, the rules in one place:**
- Rue is the character left running; she is not the girl.
- Arin is mute.
- The well keeps recordings and makes no live contact.
- A character's belief is not a fact until the truth table says so.
- The natives matter whether or not anyone plays them.
